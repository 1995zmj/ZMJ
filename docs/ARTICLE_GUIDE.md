# 添加博客文章

在仓库任意知识分类目录中创建或修改 `.md` 文件，例如 `算法/新文章.md`。

第一行建议写 `# 文章标题`，文件所在的顶层目录将自动成为分类。根目录文章归入“其他”。日期采用最近一次 Git 提交日期。

提交并推送到 `master` 后，GitHub Actions 会自动扫描文章、生成列表并发布到 GitHub Pages，无需手动编辑文章列表。

支持标题、列表、链接、图片、代码块和表格。图片相对路径按文章所在目录解析。数学公式支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`，代码块内不会渲染。Mermaid 图暂时保留源文本。

网站生成器不收录 `docs`、`tools`、`.github` 等配置目录，以及根目录的 README、WORKFLOW、AGENTS 文件。子目录 README 作为目录文章保留。

本地生成：在 `tools/blog` 目录执行 `npm ci`，然后执行 `npm run build`。生成的 `docs/articles.js` 不需要提交，线上部署会重新生成。
